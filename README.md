# Esanahia eta egitura

**Interpretazioaren zientzia**

Liburu ireki bat, euskaraz, hizkuntza naturalek esanahia adierazteko duten moduei buruzkoa.

- **Egilea:** jamendia
- **Lizentzia:** [CC BY 4.0](LICENSE)
- **Biltegia:** <https://github.com/jamendia/semantika>
- **Egoera:** eraikuntza-fasean. Pilotua: *Konposizioa* kapitulua.

## Edukia

Liburuak hizkuntzaren esanahia nola eraikitzen den azaltzen du: hitzen
esanahi lexikotik hasi eta perpausen konposizio semantikora, erreferentzia eta
kuantifikaziotik intentsionaltasunera, eta handik erabileraren pragmatikara.

Lehenengo liburukian oinarrizko arkitektura lantzen da; bigarrenean, berriz,
gai aurreratuak (presuposizioa, denbora-aspektua, pluralak, konparazioa) eta
pragmatikaren luzapenak (metafora, ironia, kortesia, etab.).

## Nola irakurri

Hasi [hitzaurrean](hitzaurrea.qmd) eta jarraitu [edukiaren
egiturari](nola-irakurri.qmd) begirada bat emanda. Kapituluak modu autonomoan
irakur daitezke, baina hurrenkera jarraitzeak asko laguntzen du.
